# Claude API 价格：按模型、输入输出和用量方式看懂真实成本

搜索“Claude API 价格”的人，通常不是只想知道一个数字，而是想弄清楚三件事：

- Claude API 到底按什么收费？
- 哪个模型适合自己的预算和任务？
- 直接使用官方 API，还是通过第三方充值更方便？

Claude API 采用按量计费，核心单位是 **每 100 万 Token**。输入 Token 和输出 Token 分开计算，输出价格通常明显高于输入价格。你实际支付多少，取决于模型、输入长度、输出长度，以及是否使用 Batch API、Prompt Caching 或区域推理等功能。

下面按当前公开价格拆开说明，并补充 WildAI 上可用的 Claude API 充值方式，方便你把“官方价格”和“实际付款路径”分开看。

## Claude API 不是按月订阅，而是按 Token 计费

Claude Pro、Claude Max 和 Claude API 是三种不同的产品形态。

Claude Pro 和 Claude Max 面向在 Claude 网页、桌面端或 Claude Code 中直接使用的用户，按照月度订阅并受使用额度限制。Claude API 面向开发者和应用程序，按照实际调用量收费。已经购买 Claude Pro 或 Claude Max，并不代表 API 调用自动包含在订阅里。Anthropic 明确将 Claude.ai 订阅和 API Console 作为独立产品处理。

API 的计算方式可以简单写成：

text
总费用 = 输入 Token 数 × 输入单价
       + 输出 Token 数 × 输出单价


例如，某次请求使用 100 万输入 Token，并生成 10 万输出 Token。如果使用输入价格为 3 美元、输出价格为 15 美元的模型，那么本次费用大约是：

text
1 × $3 + 0.1 × $15 = $4.50


这只是模型调用本身的费用，不包括其他云平台可能收取的费用，也不等于 Claude Pro 或 Max 的月费。

Anthropic 的 Claude API 通常通过 Console 预充值额度使用。购买额度后，成功的 API 调用会从余额中扣除；失败请求一般不会收费，但如果请求已经接近成功、客户端中途断开或超时，仍可能产生费用。预充值额度的有效期和退款规则也需要单独查看，官方帮助中心目前说明购买的额度通常自购买日起一年后到期，且已购买额度不可退款。

## Batch API 可以把输入和输出成本降低一半

如果你的任务不要求即时返回，可以考虑 Batch API。

Anthropic 当前说明，Batch API 对输入 Token 和输出 Token 都提供 **50% 折扣**。例如，Claude Sonnet 4.5 的标准价格是每百万输入 Token 3 美元、每百万输出 Token 15 美元；使用 Batch API 后，对应价格约为 1.5 美元和 7.5 美元。

Batch API 比较适合：

- 批量生成商品描述；
- 夜间处理文档；
- 批量分类和打标签；
- 对大量历史数据做摘要；
- 生成报告、测试样本或离线分析结果。

它不适合实时聊天、客服对话或用户正在等待结果的页面。省钱的前提是允许异步处理，不能把需要即时反馈的请求硬塞进批处理接口。

## Prompt Caching 适合重复发送相同上下文的应用

如果每次请求都包含相同的系统提示词、产品文档、代码库说明或知识库内容，Prompt Caching 可能比单纯切换模型更有效。

当前官方定价说明：

- 5 分钟缓存写入价格约为基础输入价格的 1.25 倍；
- 1 小时缓存写入价格约为基础输入价格的 2 倍；
- 缓存命中价格通常约为基础输入价格的 0.1 倍；
- 某些较新的模型使用更低的缓存读取倍率。

举个简单例子：如果你每次都把一份 50 万 Token 的产品文档放进提示词里，第一次请求之后，后续请求继续复用这部分内容，就不必每次都按完整输入价格重新计算。对于多轮客服、代码助手、企业知识库和长文档问答，缓存带来的差异可能比单纯在模型之间切换更明显。

## Claude API 和 Claude Pro、Max 到底怎么选

如果你主要是在网页里聊天、写作、改代码，通常应该比较 Claude Pro 和 Max，而不是先研究 API Token 价格。

Anthropic 当前公开的个人订阅价格包括：

| 产品 | 官方价格 | 适合人群 |
| --- | ---: | --- |
| Claude Free | $0 | 偶尔使用、体验产品 |
| Claude Pro | $20/月；年付折算约 $17/月 | 日常写作、研究、代码和普通 Claude Code 使用 |
| Claude Max 5× | $100/月起 | 使用频率较高、希望获得更多额度 |
| Claude Max 20× | $200/月 | 长时间高频使用 Claude |

Pro 的年付方案为一次性支付 200 美元，月付价格为 20 美元。Max 计划从每月 100 美元起，并提供 5 倍或 20 倍于 Pro 的使用量选项。

可以用下面这个标准判断：

- 你在网页里手动对话，选 Pro 或 Max；
- 你要在自己的网站、脚本、插件或 SaaS 产品里调用模型，选 API；
- 你只是偶尔调用几次 API，按量付费通常更容易控制；
- 你每天大量运行固定任务，应先估算 Token，再决定是否使用 Batch API 和缓存；
- 你需要稳定运行生产服务，不要把 Claude 网页订阅当作 API 替代品。

API 没有一个固定的“每月套餐价”。你可以只用几美元，也可能因为输出内容很长、调用频率很高而快速消耗几十或几百美元。

## 哪个 Claude 模型最划算

“最划算”取决于你如何使用，而不是单看输入价格。

### 轻量任务：优先 Haiku

如果任务是文本分类、关键词提取、短摘要、简单改写或结构化输出，Haiku 通常已经够用。输入价格和输出价格都低于 Sonnet 和 Opus，批量任务尤其适合。

但不要为了省 Token，把本来需要复杂推理的任务全部交给 Haiku。模型反复重试、人工修正和错误调用，也会变成成本。

### 通用开发：优先 Sonnet

Sonnet 适合作为大多数应用的默认模型。它在代码生成、内容处理、工具调用、结构化输出和普通分析之间取得了比较平衡的价格。

如果你正在做聊天机器人、知识库问答、自动写作工具、客服系统或代码辅助功能，通常可以先从 Sonnet 开始，再根据真实日志决定是否切换模型。

### 复杂推理：只在必要时使用 Opus

Opus 的输出价格明显更高。一个输出量很大的 Agent，如果默认使用 Opus，账单可能比预想中增长得快。

比较合理的做法是：

- 简单路由、分类和信息提取使用 Haiku；
- 普通回答、代码生成和大多数业务逻辑使用 Sonnet；
- 只有复杂规划、难度较高的代码重构或多步骤推理才调用 Opus。

这种分层调用通常比“所有请求都用最高档模型”更容易控制成本。

## Claude API 费用估算时别漏掉这几个因素

估算月度 API 成本时，至少要记录以下数据：

- 每月请求数量；
- 平均输入 Token 数；
- 平均输出 Token 数；
- 实际使用的模型比例；
- 是否包含长文档或完整对话历史；
- 是否启用 Prompt Caching；
- 是否适合 Batch API；
- 是否通过 AWS、Google Cloud 或 Microsoft Foundry 使用；
- 是否采用特定区域推理。

如果使用 AWS 或 Microsoft Foundry，计费方式可能通过 Claude Consumption Units，也就是 CCU 结算，云平台还可能涉及自己的账单、税费和区域价格。Anthropic 当前说明，部分区域或数据驻留选项会在标准价格上增加费用，具体要看所使用的平台和部署方式。

最实用的预算方法，是先用真实业务数据跑一小批请求，然后记录：

text
单次平均费用
× 每日请求量
× 每月使用天数


再把失败重试、缓存写入、长输出和高峰流量算进去。只拿一次短对话去推测整月成本，通常会低估实际账单。

## 结论：先分清 API、Pro 和 Max，再看价格

Claude API 的核心价格不是“每月多少钱”，而是不同模型每百万输入和输出 Token 的价格。当前可以简单记成：

- Haiku：低成本、高速度；
- Sonnet：大多数任务的平衡选项；
- Opus：高质量复杂任务，但成本更高；
- Batch API：适合离线任务，可将输入和输出价格降低约 50%；
- Prompt Caching：适合反复发送相同上下文；
- Pro 和 Max：面向直接使用 Claude 的订阅用户，不等于 API 额度。

如果你需要把 Claude 接入程序、网站或自动化工作流，建议先估算 Token 用量，再决定充值 20 美元还是 100 美元。通过 WildAI 选择 Claude API 充值时，重点核对充值账号、额度、服务费和最终支付金额，避免把第三方充值面额误认为 Anthropic 的官方 API 账单。
